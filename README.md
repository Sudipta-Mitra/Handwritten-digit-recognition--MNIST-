# Handwritten Digit Recognition using CNN (TensorFlow/Keras)

This project implements a Convolutional Neural Network (CNN) to classify handwritten digits (0–9) from the MNIST dataset. The model is built using TensorFlow & Keras and achieves high accuracy through layers like Conv2D, MaxPooling2D, Flatten, Dense, and Dropout.

The notebook includes:

- Loading and normalizing MNIST data

- Building a Sequential CNN model with multiple convolution layers

- Training using Adam optimizer and sparse_categorical_crossentropy

- Evaluating test performance and generating sample predictions

- Visualizing outputs and model summary

This project demonstrates a complete deep learning workflow—from data preparation to evaluating predictions—using an efficient CNN architecture.
